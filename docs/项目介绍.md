## 提交页可以直接贴的短介绍

我们做了一座按化学规律长出来的庭院。

玩家进来以后不是做题，是走路、观察、翻几页有出处的知识，再亲手把质子数、周期表、电子层变成能开门的能力。刘看山会指路，但不替你选路，更不会把答案念给你听。

主线是固定的，今天能玩的是序章《周期庭院》。每天早上八点，当天的知乎热榜会被酿成一处临时裂隙：玩完就走，不改主线进度。登录用知乎账号，兴趣信号只用来轻轻偏一下每日内容，不会拿来画像吓人。

它不是知识卡片墙，也不是答题闯关。我们想试试一件更笨、也更认真的事：让知乎上那些讲得清楚的知识，真的能改变你在地图上能去的地方。

## 产品说明（建议作为附件 / 长介绍）

### 这是什么

《看山异闻录》是一款桌面端优先的知识冒险游戏。第一块地图叫周期庭院，化学不是贴在墙上的名词，是这座园子怎么生长、路怎么断、门怎么开的原因。

刘看山是引路人，不是主角。玩家是一个很小的旅人。庭院很大，人很小。你先看见三颗丢掉名字的原子，再决定要不要读那张知识卡，要不要去问看山，要不要先去别的台地乱逛。

我们一开始就没想做“把知乎热榜塞进游戏皮肤”。更烦的是另一种常见做法：先弹一篇长文，再给你三道选择题。读完没有用，答对了也只是解锁下一关。周期庭院反过来：读完之后，世界得给你一个能看见的变化。台阶按原子序数排开，藤门按族打开，断桥要用化学键补上。你要是没搞懂质子数是什么，门就不会认你。

### 谁会来玩

主要是还记得中学化学、又懒得重新翻课本的人。也包括那些本来就爱在知乎上看解释、但看完就走的人。

我们不假设玩家想当学霸。有人会顺着主线把六个区域走完，有人只想跟看山贫两句，有人专门去找地图上没写的东西。这些都算玩对了。后续如果把“已经会”和“不会但想跳过”拆开，奖励会不一样，但不会拿羞辱当设计。

### 进来之后会发生什么

1. 用知乎账号进游戏。没有正式凭据时，本机可以用演示身份，不假装已经登录成功。
2. 从码头走进无名原子庭。先看氢、碳、氧三颗样本，数质子，确认它们到底是谁。
3. 打开知识卷宗。每张卡只有摘要、关键观点、作者和原文链接。我们不把别人的长回答整篇搬进来。
4. 解一个真正要动手的机关，拿到对应技能。技能不是徽章，是下次能走的路。
5. 用旧技能回头看。庭院里有几处没写在主路线上的东西：被擦掉的氖、不愿成键的凉亭、少了一条键的水分子拱门。
6. 如果你愿意，可以去当天的回声裂隙。它借用热榜的标题和线索，不复制原回答，也不改你的主线进度。

现在能玩的闭环大概是：观察 → 读一点 → 动手 → 路变了 → 带着一个没做完的问题离开。区域结束时不会弹“恭喜通关，请点下一关”。远处还有一格没署名，看山也不会替你决定要不要去。

### 知乎在里面干什么

这块我们写清楚，免得听起来像硬贴。

- **知乎登录**：走开放平台 OAuth。进来的是你，不是一个空白存档。
- **公开兴趣信号**：同步关注、创作标题这类已经授权的信号，只影响每日裂隙的轻度偏向。主线知识不跟着变。
- **热榜**：每天 08:00（上海时间）拉一次，生成当天唯一的临时地图。后台可以手动刷新，刷新只覆盖今天，不回滚主线。
- **知识出处**：主线卡按“摘要 + 关键观点 + 原文链接 + 作者”来放。接口还没接上时，界面会老实写“待接入”，不会让模型编一个作者出来。
- **刘看山**：模型只看你问了什么、你读过哪张卡、你现在会什么、你站在哪。回复压在一百字左右。他可以指方向，不可以报答案，也不可以虚构知乎里的人。模型挂了就切本地台词，主线还能玩。

还有一条我们自己设的边界：热榜标题和摘要都当不可信输入。它们可以成为当天裂隙的线索，但不能变成系统指令，也不能被当成“因为热榜这么写，所以化学是这样的”。

### 技术上怎么做的

工程很普通，没有为了演示去堆栈。

- 前端是 React + Phaser / Three，2.5D 正交庭院，电脑浏览器优先。
- 后端是 Fastify + SQLite，会话、进度、成就、每日裂隙都在服务端。
- 地图、知识卡、技能、机关、成就的定义放在共享包里，主线和每日内容走同一套结构。模型只能填协议允许的字段，乱填会被丢掉，再退回本地模板。
- DeepSeek 走 OpenAI 兼容接口，只干两件事：写很短的看山台词，以及把热榜酿成结构化的每日地图。
- 密钥只在服务端。后台能改地址和模型，读取接口只告诉你“配了没”，不把明文送回浏览器。

现在这版是可玩的序章 Demo：五个明面区域、一个隐藏的同位素穹室、知识卡、技能、机关、成就、看山对话、每日裂隙。掌握挑战、材料制作、下一块知识地图都还在后面。我们宁愿先把一座庭院做完整，再去证明内容管线能复用。

### 我们到底想验证什么

知乎上已经有很多人把难的事情讲清楚了。问题通常不在“有没有内容”，而在看完以后，这些话有没有进到你下一步的动作里。

所以我们不拿停留时长当唯一成绩。更想看的是：

- 第一次进来的人，会不会自己走完“读一张卡 → 解开一个机关”；
- 读完摘要以后，有没有人点进原文；
- 卡关之后，会不会回头翻卷宗，而不是连点跳过；
- 第二天还会不会为了那道裂隙回来看一眼。

如果这些事情发生了，这座庭院才算没有白做。如果只是一张很好看的地图，那它就还只是一张地图。
